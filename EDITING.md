# How to edit website text

You can change almost all page copy without touching code.

## One-time setup (about 2 minutes)

1. Open **[app.pagescms.org](https://app.pagescms.org)**
2. Sign in with the **GitHub** account that owns this website repo
3. Allow access to the **Lilis Website** repository when asked
4. Open the project — you should see **Home**, **About**, **Working Together**, and **Contact**

Bookmark the site. You’ll use it whenever you want to edit text.

## Everyday editing

1. Go to [app.pagescms.org](https://app.pagescms.org) and open your project  
2. Pick a page from the sidebar (e.g. **Home**)  
3. Change any text field  
4. Click **Save** / **Commit**  
5. Wait 1–2 minutes — GitHub rebuilds and publishes the site automatically  

Then check [lilidavid.com](https://lilidavid.com) (refresh if needed).

## Tips for accent-coloured words

On this site, some words appear in the green accent colour.

- Wrap a word in single asterisks to accent it: `*patterns*`  
- For a line break in a headline, use a pipe: `line one|line two`  
- For bold (not accent): `__effectiveness__`  
- For accent bold: `**structure**`

Example headline:

```text
Transform the underlying *patterns*|that keep teams stuck
```

## If something looks wrong after saving

- Wait a couple of minutes and hard-refresh the browser  
- In Pages CMS, check you saved/committed to the **main** branch  
- You can always ask for help — the old wording is still in Git history
